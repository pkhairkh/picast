boGDan Settings

Configure your boGDan receiver connection

Connection

Hostname or IP address of your Raspberry Pi on the local network. Use bogdan.local for mDNS discovery, or enter an IP like 192.168.1.100.

Default: 8585

Default: 8586

Playback

720p is recommended for Tor connections. Higher resolutions may buffer due to Tor bandwidth constraints. The ABR controller will automatically downshift if the buffer runs low.

Select the ALSA audio output device on the Pi. Choose plughw:1,0 for HDMI audio if your monitor is connected via HDMI. plughw:0,0 is typically the headphone jack. Click Refresh Devices to query the Pi for available outputs.

Privacy

Full provides maximum privacy — both URL resolution and media streaming go through Tor. Resolution Only trades metadata privacy for better playback quality (media streams directly). Off disables Tor entirely — only use for local network testing.

Behavior

Displays notifications when playback encounters errors or the connection drops.

Automatically sends the page URL to boGDan when a video element is detected. Requires trust in the sites you visit. Only activates when no other session is playing.
